# API Documentation

All functions below are exported by the native shared library (built with GraalVM `native-image`). Process models can be written in **Java** or **Python** (via GraalPy). Both compile into the same shared library. The default build includes Java models only; Python support is available as an opt-in build option (see [Build Instructions](../java_graal/README.md)).

## Water dew point and water in gas calculation
The method uses the CPA-EoS for conversion between ppm water in gas and water dew point of natural gas. It also calculates ppm water in gas at given temperature and pressure.
The calculations are done using a typical natural gas composition.

### Using Java Native Methods from C++

You can call the native methods exported from Java (via GraalVM) in your C++ program using the generated shared library and header. Below is an example of how to use the `calcWaterDewPoint` and `calcWaterInGas` methods from a C++ program.

#### Example: Calling from C++

```cpp
#include <iostream>
#include "neqsim.h"  // Include the generated header file for the shared library

int main() {
    graal_isolate_t* isolate = nullptr;
    graal_isolatethread_t* thread = nullptr;

    // Create the GraalVM isolate and isolate thread
    int create_result = graal_create_isolate(nullptr, &isolate, &thread);
    if (create_result != 0) {
        std::cerr << "Error creating GraalVM isolate!" << std::endl;
        return create_result;
    }

    // Call the calcWaterDewPoint function and store the result
    double dew_point = calcWaterDewPoint(
        thread,       // GraalVM isolate thread
        50.0,         // Example absolute pressure (bara)
        100.0         // Example water content (ppm)
    );
    std::cout << "Result of calcWaterDewPoint function call: " << dew_point << " C" << std::endl;

    // Call the calcWaterInGas function and store the result
    double water_in_gas = calcWaterInGas(
        thread,       // GraalVM isolate thread
        50.0,         // Example absolute pressure (bara)
        10.0          // Example temperature (C)
    );
    std::cout << "Result of calcWaterInGas function call: " << water_in_gas << " ppm (mole/volume)" << std::endl;

    // Destroy the GraalVM isolate
    int destroy_result = graal_detach_all_threads_and_tear_down_isolate(thread);
    if (destroy_result != 0) {
        std::cerr << "Error destroying GraalVM isolate!" << std::endl;
        return destroy_result;
    }

    return 0;
}
```

- Make sure to link against the generated shared library (e.g., `neqsim.so`) when compiling your C++ program.
- The header file `neqsim.h` is generated by GraalVM native-image and provides the function signatures.
- Always create and destroy the GraalVM isolate as shown above.

## Python-Based Models (via GraalPy)

The following functions are implemented in **Python** and exposed via a thin Java `@CEntryPoint` wrapper. They are compiled into the same shared library as the Java models.

> **Build variant note:** Python models require the **with-python** build (e.g., `-Pnative-linux,with-python`). In **default** builds (no Python runtime), these functions are still exported but return `quality=0` with `-999.0` output values and a clear error message.

### How neqsim Is Accessed from Python

GraalPy provides built-in Java interop via the `java` module. This is **not** JPype or any bridge — it runs on the same VM:

```python
import java

# Access any Java class by its fully qualified name
SystemSrkEos = java.type("neqsim.thermo.system.SystemSrkEos")
ThermodynamicOperations = java.type(
    "neqsim.thermodynamicoperations.ThermodynamicOperations"
)

# Use them exactly like in Java
fluid = SystemSrkEos(25.0, 50.0)
fluid.addComponent("methane", 0.85, "mol/sec")
fluid.setMixingRule(2)

ops = ThermodynamicOperations(fluid)
ops.TPflash()

density = fluid.getPhase("gas").getDensity("kg/m3")
```

### Example: Python Dew Point Calculation (`PY_run_dewpoint_calculation`)

Calculates the hydrocarbon dew point temperature and gas density for a typical natural gas mixture using a Python process model.

#### Process Steps:
1. Creates a natural gas fluid (typical composition) using neqsim's SRK equation of state.
2. Runs a TP flash at the given temperature and pressure.
3. Reads gas-phase density from the flash result.
4. Calculates the hydrocarbon dew point temperature at the given pressure.
5. Writes results to the provided `CDoublePointer` objects and `CIntPointer` for quality.

> **Note:** This model is written in Python (`dewpoint_process.py`) and calls neqsim Java classes directly via GraalPy's `java.type()` interop — no JVM bridge (JPype) is needed.

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `thread` | `graal_isolatethread_t*` | The isolate thread for the native entry point. |
| `temperature` | `double` | Gas temperature (°C). |
| `pressure` | `double` | Gas pressure (bara). |
| `gas_flow_rate` | `double` | Gas flow rate (kg/hr). |
| `dew_point_temperature` | `double*` | Pointer to write the hydrocarbon dew point temperature (°C). |
| `gas_density` | `double*` | Pointer to write the gas density (kg/m³). |
| `quality` | `int*` | Pointer to write the quality of the calculation indicating bad (0) or success (1). |

#### Example: Calling from C++

```cpp
#include <iostream>
#include "neqsim.h"

int main() {
    graal_isolate_t* isolate = nullptr;
    graal_isolatethread_t* thread = nullptr;
    graal_create_isolate(nullptr, &isolate, &thread);

    double dew_point = 0, gas_density = 0;
    int quality = 0;

    PY_run_dewpoint_calculation(thread,
        25.0,           /* temperature [°C]  */
        50.0,           /* pressure [bara]   */
        1000.0,         /* gas flow [kg/hr]  */
        &dew_point,
        &gas_density,
        &quality);

    if (quality == 1) {
        printf("Dew point: %.2f °C\n", dew_point);
        printf("Gas density: %.2f kg/m³\n", gas_density);
    }

    graal_tear_down_isolate(thread);
    return 0;
}
```
